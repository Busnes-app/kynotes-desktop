# KyNotes Desktop

Desktop client for [KyNotes](https://github.com/Busnes-app/KyNotes-server) on Windows, macOS, and Linux, providing offline-capable, end-to-end encrypted notes as part of the [busnes.app](https://busnes.app) suite.

## Status

This repository is an early placeholder. The desktop client implementation has not yet been published here.

In the meantime, see the [KyNotes server (`KyNotes-server`)](https://github.com/Busnes-app/KyNotes-server) repository for the server and web client.
